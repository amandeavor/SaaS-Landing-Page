# MemberFlow Landing Page

A responsive marketing-site concept for a fictional membership platform.

## Live demo

[saas-landingpage-amandeavor.netlify.app](https://saas-landingpage-amandeavor.netlify.app)

![MemberFlow preview](preview.png)

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide icons
- Netlify configuration

## Local development

```bash
git clone https://github.com/amandeavor/saas-landing-page.git
cd saas-landing-page
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

This is a frontend design and implementation sample. It does not include a membership backend, authentication, payments, or a real customer dataset.
