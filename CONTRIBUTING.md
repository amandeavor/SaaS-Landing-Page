# Contributing to MemberFlow Landing Page

Thank you for checking out this landing page project.

## Development Setup

```bash
git clone https://github.com/amandeavor/saas-landing-page.git
cd saas-landing-page
npm install
npm run dev
```

## Quality Commands

Before submitting a pull request:

```bash
npm run build
```

## Note

This repository is a frontend marketing-site design sample. Contributions focused on typography, animations, responsive design, and component polish are welcome.
